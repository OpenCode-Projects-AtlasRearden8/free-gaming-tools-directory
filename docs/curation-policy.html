Curation policy

What gets in, what stays out, and how entries are kept honest. Plain rules, written before the list, not after.

Scope

This directory lists companion tools for gamers — software that lives next to your games, not the games themselves. Five categories only:

  1. Save managers (backup, restore, migration)
  2. Achievement and backlog tools
  3. Controller mappers
  4. Screenshot organizers
  5. Wiki note-takers

Out of scope: the games themselves (that's our separate free-open-source-games-directory), game-specific trackers like FFXIV tools (separate project), emulators, cheats/trainers, game installers or repacks, and anything that violates a game's terms of service.

Inclusion rules

Every listed tool must pass all of these. One strike and it stays out:

  • Free to use. No purchases, subscriptions, or trials required for the core function. Free tiers of paid products are excluded unless the free tier covers the whole job described.
  • Respectable source. The tool comes from an official site, a maintained repository, or a project with an established community. We do not link mirrors, forum reposts, or bundled installers.
  • No dirty tricks. No adware, no bundling, no account walls to unlock basic features, no telemetry required to function, no dark patterns in the installer.
  • Actively usable. Maintained or demonstrably stable. Abandoned is fine if it still works and is famously reliable (looking at you, JoyToKey). Broken is not.
  • Clear purpose. We can describe what it checks and does in one plain-English sentence. If we can't explain it simply, we won't list it confusingly.

Every entry has four fields

  • What it checks — a one-sentence, concrete description of what the tool actually inspects or handles (save locations, achievements, inputs, screenshots, notes). No marketing voice.
  • Platform — where it runs, in plain words.
  • Offline-first flag — Offline-first (works fully with no internet), Partly offline (offline after setup or with optional sync), or Needs internet (web tool or requires accounts/servers).
  • Verdict — one line in Dylan's plain voice. Who it's actually for, and the honest catch if there is one. Never condescending, no hype.

Dylan's voice rules

Verdicts are written like a friend explaining it over coffee:

  • Lead with what it's good for, not the company line.
  • Say the catch out loud (huge settings surface, old UI, needs an account).
  • Serious things stay serious; a lost save file is treated like a lost save file.
  • No jargon without translation. No "robust", no "seamless", no "game-changing".

Keeping it honest

  • Entries are reviewed with the tool review checklist before going in.
  • Links are checked: https only, pointing to official sources.
  • Corrections welcome. If a tool has changed for the worse, the entry gets fixed or removed — the list is more important than any single entry.
  • No paid placements, no sponsorships, no affiliate links. Ever.

Safety and privacy

  • No personal data is collected by this site — it's a static HTML page with JavaScript that runs entirely in your browser.
  • No tracking scripts, no analytics, no cookies.
  • We only link to tools; we don't host installers. Download from the official source and verify you're there.
