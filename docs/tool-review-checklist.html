Tool review checklist

Run every candidate tool through this list before it goes in the directory. If any box is unchecked, it waits.

Before it goes in

  • □ Free for the full described function (no paywall, no trial, no free-tier trap)
  • □ Downloaded from the official site or maintained repository
  • □ Installer/source checked: no adware, no bundling, no surprise checkboxes
  • □ Runs on at least one current mainstream OS without unsupported hacks
  • □ Actually used for its described purpose by the reviewer (not just the README)
  • □ Respectable reputation: no unresolved malware reports we can find
  • □ "What it checks" sentence is concrete and verified true
  • □ Offline flag tested: does it work with the network off? Label accordingly
  • □ Verdict written in Dylan's plain voice, catch included
  • □ URL is https and points to the official source
  • □ Entry not a duplicate of (or redundant with) an existing entry
  • □ Terms-of-service check passed: nothing that reads against a game's EULA

On every re-review

  • □ Tool still available and downloadable
  • □ Still free for the described function
  • □ Still behaves as the entry describes (UIs drift; entries shouldn't)
  • □ Verdict still true — if the catch became a dealbreaker, the entry goes, not the catch

Removal policy

An entry is removed, not merely annotated, if it: goes paid for its core function, adds bundling or aggressive tracking, becomes unmaintained and broken, or turns out to be unsafe. The directory's job is to be trustworthy, not complete. A shorter honest list beats a longer useful-looking one.
